# TTMediaBot — Russian Edition

Привет! Меня зовут **DJ Dancho**, и это мой форк [TTMediaBot](https://github.com/gumerov-amir/TTMediaBot) — медиа-бот для TeamTalk 5, переделанный специально для тех, у кого серверы в России.

> Оригинальный проект: [gumerov-amir/TTMediaBot](https://github.com/gumerov-amir/TTMediaBot)
> Мой репозиторий: [Daket52i/TTMediaBot-by-dancho](https://github.com/Daket52i/TTMediaBot-by-dancho)

## Что изменено

- **Русские сервисы:** Rutube (видео), Музфонд и Хитмо (музыка) — работают без VPN и блокировок
- **YouTube убран полностью:** из России он не работает, поэтому сервис отключён, а из установщика убраны Node.js и запрос cookies.txt
- **VK и Яндекс Музыка возвращены:** код взят из официального репозитория без переписывания; включаются в `config.json`, нужен токен аккаунта
- **TeamTalk SDK 5.22a:** библиотека скачивается установщиком под архитектуру сервера
- **Починены источники:** Музфонд переехал на muzofond.su и отдаёт mp3 напрямую, скачивание проверяется на пустой файл и HTML вместо музыки
- **Автозапуск и рестарт:** настроен systemd-сервис + ежедневный рестарт в 3:00 ночи

## Сервисы

| Сервис | Команда | Описание |
|--------|---------|----------|
| **Музфонд** | `sv mf` | Музыка, mp3 (основной сервис) |
| **Хитмо** | `sv hitmo` | Музыка, mp3 |
| **Rutube** | `sv rt` | Видео с Rutube (API, без авторизации) |
| **VK** | `sv vk` | Музыка ВК — нужен токен в `services.vk.token` |
| **Яндекс Музыка** | `sv yam` | Яндекс Музыка — нужен токен в `services.yam.token` |

Переключение: отправьте боту `sv mf`, `sv hitmo`, `sv rt`, `sv vk` или `sv yam`.

Сервис без токена не включается и появляется в списке сервисов с причиной —
например `vk (Error: Не указан токен VK (services.vk.token))`. Подробнее — в
разделе «Токены VK и Яндекс Музыки».

## Установка

### Быстрый старт (рекомендуется)

```bash
wget https://raw.githubusercontent.com/Daket52i/TTMediaBot-by-dancho/master/install_git_clone.sh
chmod +x install_git_clone.sh
sudo ./install_git_clone.sh
```

Скрипт сам установит зависимости (Git, Docker, ffmpeg), склонирует репозиторий и запустит менеджер ботов.

### Альтернатива — локальная установка (без Docker)

```bash
git clone https://github.com/Daket52i/TTMediaBot-by-dancho.git
cd TTMediaBot-by-dancho
sudo ./install.sh
```

Установит Python venv, Node.js зависимости, ffmpeg и TeamTalk библиотеки напрямую на сервер.

## Конфигурация

1. Скопируйте шаблон конфига:
   ```bash
   cp config_default.json config.json
   ```

2. Отредактируйте `config.json` — заполните данные вашего TeamTalk сервера:
   ```json
   {
       "teamtalk": {
           "hostname": "ваш-сервер.ru",
           "tcp_port": 10333,
           "udp_port": 10333,
           "username": "bot",
           "password": "ваш_пароль",
           "channel": "/Канал"
       }
   }
   ```

3. Сервисы `rt`, `mf`, `hitmo`, `vk` и `yam` уже есть в `config_default.json` — скопируйте и отредактируйте.

## Автозапуск и рестарт

Если установка была через Docker — автозапуск настроен автоматически.

Для ручной установки (systemd):
```bash
# Сервис: /home/bot/.config/systemd/user/TTMediaBot.service
# Автозапуск: loginctl enable-linger bot
# Ежедневный рестарт в 3:00: ttbot-restart.timer
```

Проверить статус:
```bash
su - bot -c 'XDG_RUNTIME_DIR=/run/user/1002 systemctl --user status TTMediaBot'
```

## Токены VK и Яндекс Музыки

Muzofond, Hitmo и Rutube работают **без авторизации**. VK и Яндекс Музыке нужен
токен вашего аккаунта — без него сервис просто не включается.

```json
{
    "services": {
        "vk":  { "enabled": true, "token": "ваш_токен_vk" },
        "yam": { "enabled": true, "token": "ваш_токен_яндекса" }
    }
}
```

Для Яндекса нужна подписка Плюс, иначе треки приходят только превью.
Пакеты `vk-api` и `yandex_music` ставятся установщиком вместе с остальными
зависимостями; на уже работающей установке — `pip install vk-api yandex_music`
внутри venv. Токен чувствителен: `config.json` в репозиторий не коммитится.
